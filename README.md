# EDA PROJECT
# Student Health Data Analysis – EDA

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a Student Health Dataset. The main objective is to understand the data, identify patterns, analyze health-related information, and gain meaningful insights using Python.

## Project Objectives

- Understand the structure of the dataset.
- Identify missing and duplicate values.
- Perform data cleaning.
- Conduct statistical analysis.
- Analyze student health information.
- Explore relationships between different variables.
- Present insights through data visualizations.

## Dataset Description

The dataset contains the following columns:

- Student ID
- Age
- Gender
- Height
- Weight
- Blood Type
- BMI
- Temperature
- Heart Rate
- Blood Pressure
- Cholesterol
- Diabetes
- Smoking

## Tools and Technologies

- Programming Language: Python
- Environment: Jupyter Notebook
- Libraries: Pandas, NumPy, Matplotlib, Seaborn

## Project Workflow

1. Imported the required Python libraries.
2. Loaded the dataset.
3. Explored the dataset structure and data types.
4. Checked for missing and duplicate values.
5. Performed data cleaning.
6. Conducted statistical analysis.
7. Used GroupBy operations for comparison.
8. Created data visualizations.
9. Analyzed the results and findings.

## Data Visualization

The following visualizations were used:

- Count Plot
- Histogram
- Scatter Plot
- Box Plot
- Correlation Heatmap

## Key Findings

- Male and female students are almost equally distributed.
- Blood groups B and O are slightly more common than A and AB.
- Relationships between age, height, weight, BMI, heart rate, and cholesterol were explored.
- BMI, weight, and cholesterol were compared across different groups.
